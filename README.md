# Sage-Gold

Отдельный статический шаблон свадебного сайта в молочно-шалфейной акварельной стилистике.

## Локальный запуск

```powershell
npm run dev
```

Откройте `http://127.0.0.1:4178/3`, где `3` — ID приглашения в Xano.

## Проверка

```powershell
npm run check
```

Данные загружаются через `GET https://x8ki-letl-twmt.n7.xano.io/api:X8-e2j1w/priglosi/{id}`. RSVP использует подтверждённый существующими проектами поток: свежий GET, добавление гостя и `PATCH /priglosi/{id}/full`.

Проект готов к развёртыванию на Vercel.
